 My Web Design Experience: Challenges and Successes

While designing and developing this portfolio website, I faced several technical and design challenges that required research, testing, debugging, and continuous improvement. Throughout the process, I learned how to solve problems independently while also benefiting from guidance and feedback from ChatGPT.

 Challenges I Faced

 Background Image Adjustment

Initially, the background image did not display properly across different screen sizes and sometimes left empty spaces. I had to carefully adjust background-size, background-position, and other CSS properties to ensure the image displayed correctly and consistently.

 Responsiveness Across Devices

When testing the website on tablets and mobile devices, some elements appeared too small or overlapped outside the screen. To solve this issue, I implemented media queries and adjusted margins, font sizes, spacing, and layouts to improve the user experience on different devices.

Element Spacing Management

Maintaining consistent spacing between sections was challenging, especially when resizing the browser window. I had to fine-tune padding, margins, and alignment to create a clean and balanced layout.

 Content Arrangement

Some elements, including titles, buttons, images, and project cards, needed to be reorganized and resized to improve readability and navigation. I refined the layout several times before achieving a balanced design.

 Project Layout Design

Designing the Projects section required multiple adjustments to image sizing, spacing, card dimensions, and content alignment. I experimented with different layouts before creating a project showcase that looked professional and visually balanced.

 Correcting and Optimizing Code

During development, I discovered several coding issues that required correction and optimization. Through debugging and testing, I improved the structure and organization of both my HTML and CSS files.

Background Image Format Conversion

I needed to edit the background image and convert it into a suitable JPG format so it could be displayed properly on the website. Without this conversion, the image was not rendered correctly by the browser.

---

 What I Did Well

 Professional Layout Design

I created a modern portfolio layout with a clear visual hierarchy that helps visitors easily navigate through the website sections.

 Responsive User Interface

I successfully adapted the website for desktops, tablets, and mobile devices using CSS Flexbox and Media Queries to provide a smooth and user-friendly experience.

 Consistent Color Theme

I maintained a consistent yellow, black, and white color scheme throughout the website, creating a professional appearance and strong visual identity.

Interactive Elements

I implemented hover effects, transitions, and interactive buttons that improve user engagement and make the website feel more dynamic.

Project Showcase Section

I designed a dedicated Projects section that highlights my work using images, descriptions, and a clean card-based layout.

 Contact Section

I created a simple and accessible contact area that allows visitors to quickly find my email address and phone number.

Social Media Integration

I successfully linked external social media profiles, including LinkedIn, GitHub, Facebook, and X (Twitter), making it easy for visitors to connect with me online.

 Clean Code Organization

I organized my HTML and CSS files using meaningful class names and a clear structure, making the code easier to read, maintain, and update.

 Continuous Improvement

Throughout the project, I continuously refined the layout, spacing, typography, colors, and overall appearance based on testing and feedback until I achieved a result that I was satisfied with.

---

 Conclusion

This project helped me strengthen my understanding of HTML and CSS while improving my problem-solving and debugging skills. It also gave me practical experience in responsive web design, layout organization, and creating a professional portfolio website. Through continuous testing and improvement, I was able to transform my ideas into a functional and visually appealing website.
